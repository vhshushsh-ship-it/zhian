## 题型1：求极限

### 第一步：先化简

1. 乘除因子 → 等价无穷小替换：$\sin x \sim x$、$\tan x \sim x$、$1-\cos x \sim \dfrac{x^2}{2}$
2. 乘除因子的非零极限 → 先算出来
3. 加减高阶项消不掉 → 泰勒展开
4. 不好展开 → 洛必达法则
5. $\infty/\infty$ 且多项式 → 抓大头（只看最高次项）
