一、数列极限
1. 定义：ε-N 语言
limn→∞ an = A ⇔ ∀ε>0，∃N∈N+，当 n>N 时，恒有 |an−A|<ε
理解要点：ε 要能"任意小"；N 只要求存在、不要求唯一
高频考"对定义表述的正误判断"
2. 极限的性质
• 唯一性：若极限存在，则必唯一
• 有界性：收敛数列必有界（局部有界）
• 保号性（设 limn→∞ an = A）：
① 由极限符号推数列符号：若 A>0（或 A<0），则 ∃N∈N+，当 n>N 时，an>0（或 an<0）
② 由数列符号推极限符号：若 ∃N∈N+，当 n>N 时，an≥0（或 an≤0），则 A≥0（或 A≤0）
前提极限 A 得存在（limn→∞ an = A 必须成立，才能由数列符号推出极限符号）
易错陷阱②方向（逆命题）结论只能到"或等于 0"，不能推出严格大于 0
3. 收敛与子列 高频
• 数列 {an} 收敛 ⇒ 其任一子列都收敛且极限相同
• 判发散：找一个子列发散，或找两个极限不同的子列（常用奇、偶子列）
• 若奇数项子列 {a2k−1} 与偶数项子列 {a2k} 都收敛且极限相等 ⇒ 原数列 {an} 收敛
4. 两个准则的条件
• 单调有界准则：单调递增且有上界（或单调递减且有下界）⇒ 收敛
• 夹逼准则：若 an≤bn≤cn，且 limn→∞ an = limn→∞ cn = A，则 limn→∞ bn = A（两边极限要相等）
• 注意：有界不一定收敛（如 an = (−1)n）；单调不一定收敛（要有界）
二、函数极限
1. 定义：ε-δ、ε-X 语言
x→x₀：limx→x₀ f(x) = A ⇔ ∀ε>0，∃δ>0，当 0<|x−x₀|<δ 时，恒有 |f(x)−A|<ε
x→∞：limx→∞ f(x) = A ⇔ ∀ε>0，∃X>0，当 |x|>X 时，恒有 |f(x)−A|<ε
2. 左右极限
limx→x₀ f(x) 存在 ⇔ 左极限 limx→x₀⁻ f(x) 与右极限 limx→x₀⁺ f(x) 都存在且相等
易错陷阱用于分段点、绝对值、取整点
易错陷阱极限存在与该点函数值 f(x₀) 无关（甚至可以没定义）
3. 局部有界性
定理：若 limx→x₀ f(x) 存在，则 ∃δ>0，f(x) 在去心邻域 Ů(x₀, δ) 内有界（即局部有界）
• 极限存在 ⇒ 局部有界；反之不成立
• 反例：f(x) = sin(1/x)，在 x₀ = 0 附近有界，但 limx→0 sin(1/x) 不存在
注意是"去心邻域"内局部有界，不是整个定义域上有界
4. 保号性（设 limx→x₀ f(x) = A）
① 由极限符号推函数符号：若 A>0（或 A<0），则 ∃δ>0，当 x∈Ů(x₀, δ) 时，f(x)>0（或 f(x)<0）
② 由函数符号推极限符号：若 ∃δ>0，当 x∈Ů(x₀, δ) 时，f(x)≥0（或 f(x)≤0），则 A≥0（或 A≤0）
前提极限 A 得存在（limx→x₀ f(x) = A 必须成立，才能由函数符号推出极限符号）
易错陷阱保号性逆推只能得到 f ≥ 0（或 f ≤ 0），不能得 f > 0（或 f < 0）
5. 保号性的推论
若 f(x)>g(x)，且 limx→x₀ f(x) = A、limx→x₀ g(x) = B，则 A≥B（前提：A、B 存在）
推导：f(x)>g(x) ⇒ f(x)−g(x)>0 ⇒ limx→x₀ [f(x)−g(x)] ≥ 0 ⇒ A−B≥0 ⇒ A≥B
易错陷阱严格大于推出的是大于等于，不是严格大于！
一句话记住：函数推极限，严格变非严——不管函数那边是 > 还是 ≥，极限这边都只能到 ≥，等号"落"在极限上。
6. 极限不存在 ≠ 和/积不存在
两个极限都不存在的函数，其和/积极限可能存在。例：f(x) = sin(1/x)、g(x) = −sin(1/x)（x→0 均无极限），但 f+g = 0，limx→0 [f(x)+g(x)] = 0 存在。
三、无穷小与无穷大 （概念题重灾区）
1. 无穷小量的概念
定义：若函数 f(x) 当 x→x₀（或 x→∞）时的极限为零，即 limx→x₀ f(x) = 0，则称 f(x) 为该趋向过程下的无穷小量。
注意无穷小是一个变量（极限为 0 的函数），不是"很小的数"；必须指明趋向过程；0 是无穷小量，但无穷小量不只是 0。
2. 无穷小的比较（设 α(x)→0，β(x)→0，同一极限过程下）
类型条件记号 / 读法
高阶无穷小lim α(x)/β(x) = 0α(x) = o(β(x))，读作 α 是 β 的高阶无穷小
低阶无穷小lim α(x)/β(x) = ∞—
同阶无穷小lim α(x)/β(x) = C ≠ 0—
等价无穷小lim α(x)/β(x) = 1α(x) ~ β(x)
k 阶无穷小lim α(x)/[β(x)]k = C ≠ 0α 是 β 的 k 阶无穷小
本质：阶的比较 = 求两个无穷小比值的极限。
比较阶时只看主项，非主项可省略
若 α(x) 展开后是多项之和，如 α(x) = A·xp + B·xq（p<q，A≠0），比较阶时只取最低次幂的主项 A·xp，更高阶的小项 B·xq 可以省略。
为什么：limx→0 α(x)/(A·xp) = limx→0 [A·xp + B·xq]/(A·xp) = 1 + (B/A)·xq−p → 1（因 q−p>0，xq−p→0）。即 α(x) ~ A·xp，高阶小项在比值中趋于 0、自动消失，不影响阶的判定。
例子（x→0）：sinx + x² ~ x（x² 是高阶项，省略）；x² + x³ ~ x²（x³ 省略）；x − 2x³ ~ x
易错省略非主项的前提是主项不抵消。若主项互相抵消（如 x − sinx），主项 x 与 sinx ~ x 抵消后，次项才升格为主项：x − sinx ~ x³/6——必须往下再拆一项，不能笼统说"x − sinx 等价于 0"。
说明：推导以 x→0 为例，本质对同一趋向过程（如 x→∞）都成立；"主项抵消"是 ⑤ 求极限时泰勒展开的伏笔，务必保留。
振荡因子若极限过程中含振荡因子（如 sin(1/x)）且整个极限存在，则振荡因子前的系数必须 →0，否则极限不存在（振荡不收敛）。振荡 × 趋于 0 = 0。例：limx→0 x·sin(1/x) = 0（x→0，sin(1/x) 振荡有界）。
3. 无穷小的性质
运算结论正误
有限个无穷小的和仍是无穷小✓ （必须是有限个！）
有限个无穷小的积仍是无穷小✓
无穷小量与有界量的积仍是无穷小✓ （非常重要！）
无穷多个无穷小的和仍是无穷小× 反例：n 个 1/n 相加 = 1（n→∞，每个 1/n 都是无穷小，但和不为 0）
无穷小量 × 无界量仍是无穷小× 反例：(1/x)·x = 1（x→∞，1/x 为无穷小、x 无界）
两个无穷小的商仍是无穷小× 反例：x/x = 1（x→0，分子分母均为无穷小）
4. 无穷大与无界的辨析 必考陷阱
• 无穷大 ⇒ 一定无界
• 无界不一定是无穷大（无界允许"偶尔跑回来"，无穷大要求"一直大下去"）
• 典型反例：f(x) = x·sinx（x→∞）无界但不是无穷大
5. 无穷小与无穷大的关系
非零无穷小的倒数是无穷大（同一趋向过程下）。
6. 无穷大量的性质
运算结论正误
两个无穷大的积仍为无穷大✓
无穷大 + 有界变量仍为无穷大✓
两个无穷大的和仍为无穷大× 反例：f(x)=x，g(x)=1−x（x→∞ 均无穷大，但 f+g=1）
无穷大 × 有界量仍为无穷大× 反例：x·sinx（x→∞，sinx 有界）
7. 常用无穷大量的比较（增长速度排序） ∞/∞ 判型用
x→+∞ 时：lnαx << xβ << ax（α>0, β>0, a>1）——对数增长 << 幂函数增长 << 指数增长。
验证：limx→+∞ ln x / x0.0…01 = 0 ✓
n→∞ 时：lnαn << nβ << an << n! << nn——对数 << 幂 << 指数 << 阶乘 << nn。
验证举例：limn→∞ 2n/n! = 0 ✓（指数比阶乘慢）；limn→∞ n10000/2n = 0 ✓（幂比指数慢）；limn→∞ ln n/√n = 0 ✓（对数比幂慢）。
用法：分子分母都是无穷大时，谁的"增长档"靠后谁主导结果（高档/低档 → ∞；低档/高档 → 0）。
8. ∞−∞ 型未定式的处理 化成 0/0
四项选一种：
• 两项是分式（A/B − C/D）→ 通分；
• 含根号差（√−√ 或 √−x）→ 有理化（乘共轭因式）；
• x→∞ 含根号且次数高 → 提公因式 x；
• x→∞ 含 1/x → 倒代换 t=1/x。
例题：limx→∞ [∛((x+a)(x+b)(x+c)) − x]
① 提 x 出来：三次根号化成 x·[(1+u)1/3 − 1]；
② 等价无穷小：(1+u)α − 1 ~ αu，这里 α=1/3；
③ 乘积展开只取一次项：(1+at)(1+bt)(1+ct) = 1 + (a+b+c)t + o(t)，高次项 t→0 时可忽略。
9. 极限结果的判定（x→∞）
• 极限存在且有限 → 得到确切值（函数连续 / 极限存在时）
• 极限为 ∞ → 无穷大
• 能任意大但会回到小值、极限不存在 → 无界但非无穷
• x→有限点时，无穷大通常来自分母趋于 0（或 tan 之类）
10. 分式极限判定（一张表背下来）：limx→x₀ f(x)/g(x) = A（有限）
已知 \ 推出A ≠ 0A = 0
分母 g(x)→0分子 f(x)→0（同阶）分子 f(x)→0（高阶）
分子 f(x)→0分母 g(x)→0（同阶）分母 g(x) 任意（推不出）
卡片一：A ≠ 0（极限为非零常数），limx→x₀ f(x)/g(x) = A ≠ 0
① 已知分母 g(x)→0 ⇒ 分子 f(x) 必→0（反证：若 f(x)→C≠0，则 f/g→C/0=∞，不是有限数，矛盾）
② 已知分子 f(x)→0 ⇒ 分母 g(x) 必→0（反证：若 g(x)→C≠0，则 f/g→0/C=0，与 A≠0 矛盾）
卡片二：A = 0（极限等于 0），limx→x₀ f(x)/g(x) = 0
① 已知分母 g(x)→0 ⇒ 分子 f(x) 必→0（反证同卡片一）；但此时 f 缩得比 g 快，f 是 g 的高阶无穷小。例：x²/x→0
② 已知分子 f(x)→0 ⇒ 分母 g(x) 随便，推不出（分子缩得太快，分母配不配合都行）：
• 分母也→0（比分子慢）：x²/x→0，g→0
• 分母不动：x²/(x+1)→0，g→1
• 分母甚至→∞：x²/(1/x) = x³→0，g→∞
四、连续与间断点
1. 连续的定义
limx→x₀ f(x) = f(x₀)，三要素：① 在 x₀ 有定义 ② limx→x₀ f(x) 存在 ③ 二者相等。
推出关系可导 ⇒ 连续 ⇒ 极限存在（反之均不成立）
2. 间断点分类 高频选择
类型判定
第一类 · 可去左右极限存在且相等，但不等于函数值或无定义
第一类 · 跳跃左右极限都存在但不相等
第二类 · 无穷至少一侧极限为 ∞
第二类 · 振荡极限不存在且振荡（如 sin(1/x)）
第一类共同点：左右极限存在；第二类共同点：左右极限至少有一个不存在。
3. 间断点藏在哪：先列可疑点，再逐个求极限、定类型
间断点只藏在两类地方：函数无定义的点 + 分段函数的分段点。
一、无定义的点（初等函数间断点的唯一来源）：初等函数在定义域内处处连续，间断点只在定义域外。
函数形式可疑点
分式 P/Q分母 Q(x) = 0
tanx、secxcosx = 0（x = π/2 + kπ）
cotx、cscxsinx = 0（x = kπ）
lnu、logau真数 u = 0（或 ≤ 0）
1/x、1/(x−a)x = 0、x = a
e1/x、sin(1/x)x = 0
偶次根号 √uu < 0 的边界
二、分段函数的分段点（最主要来源）：表达式发生切换的点必须重点判断，例如：
• 绝对值展开处：|x| 在 x = 0
• 取整函数 [x]：每个整数点
• 分段定义的衔接点
• 由极限式定义的函数的分界点
4. 极限式定义函数题型：f(x) = limn→∞ gn(x) 高频题型
极限式中含 x（x 是参数，n→∞ 是极限变量）：先求出 f(x)，再定定义域 I 与连续区间 J。
本质思路（先想通这个再做题）
函数的定义要求：定义域内每个 x 对应唯一确定的实数 y = f(x)。而 f(x) = limn→∞ gn(x) 中，这个"y"是由 n→∞ 的极限给出来的——所以要先对每个 x 确认：n→∞ 时 gn(x) 能不能给出唯一一个确切的数。
两种"给不出"的情况，对应的 x 都不能进定义域：
① 没有一个确切的数：极限不存在（振荡不收敛、趋于 ∞）；
② 对应了两个值：不同子列趋于不同值（如奇偶子列），一个 x 同时对应两个 y，破坏"唯一确定"。
第一步：求极限，写分段表达式（先找分界点，再分类讨论）
极限式中含有分界点分类依据
xn、x2n（最常见）x = ±1|x|<1 时 xn→0；|x|>1 时 xn→∞
指数 a(·)底数 = 1底数 >1 发散、<1 趋于 0
分式分母为 0 的点该点单独讨论
三个必须单独算的点：① 分界点本身（如 x=±1）直接代入；② 分母为 0 的点（可能无定义）；③ |x|>1 时注意 xn 奇偶子列符号相反，可能极限不存在。
第二步：定定义域 I（逐点筛选）
I = { x ｜ 极限存在且唯一（有限值）且表达式有意义 }。
✗ 排除：振荡、子列不等（一个 x 对应两个值）、趋于 ∞（无穷大不是确切的数）、表达式无定义（分母为 0）。
依据：函数要求每个 x 对应唯一确定的 f(x)——极限给不出唯一值的 x 不能进定义域（振荡、子列不等、趋于 ∞ 都属于"给不出唯一值"）。
第三步：定连续区间 J（查三要素）
每个分段点：f(x₀) ＝ limx→x₀⁻ f(x) ＝ limx→x₀⁺ f(x)？
• 三者相等 → 连续；不等或无定义 → 间断，从 J 中剔除该点。
• 分段区间内部（常数或连续初等函数）→ 直接连续。
例题落点：f(x) = limn→∞ (x2n−x)/(x2n+1)
分段：|x|<1 时 f = −x；x = 1 时 f(1) = 0；x = −1 时 f(−1) = 1；|x|>1 时 f → 1。
I = (−∞,+∞)（分母 x2n+1 ≥ 1 永不为 0，各点极限都存在）。
x = 1：左极限 −1、右极限 1、f(1) = 0，左右不等 → 跳跃间断（第一类）；x = −1：左极限 1、右极限 −1→1、f(−1) = 1，三者相等 → 连续。
J = (−∞,1) ∪ (1,+∞)。
五、求极限的方法 （按求的对象分三大类：A 函数 ✓ / B 数列 ✓ / C 抽象函数 ✓）
按"求的对象"分三类：函数、数列、抽象函数；每类的典型题型与常用工具后续补充。
A. 函数求极限 （具体函数，x→x₀ 或 x→∞）
做题按三步走；第三步没算出结果就回第二步（化简 ⇄ 判型迭代）。
第一步：看是否需要分左右极限
需要分左右的情形（不能写一个极限，必须分别求 f(x₀−0)、f(x₀+0)，相等才存在）：
• 分段函数在分段点
• e∞ 型（如 e1/x 在 x→0，左右极限不同）
• arctan∞（x→∞ 时左右不同：arctan(+∞)=π/2、arctan(−∞)=−π/2）
• 含 |x|、取整 [x]
例题：limx→0 (e1/x−1)/(e1/x+1)
右极限（x→0+）：1/x→+∞，e1/x→+∞，分子分母同除以 e1/x：limx→0+ (1−e−1/x)/(1+e−1/x) = (1−0)/(1+0) = 1
左极限（x→0−）：1/x→−∞，e1/x→0，直接代：(0−1)/(0+1) = −1
结论：limx→0+ f(x)=1、limx→0− f(x)=−1，左右不相等 ⇒ 原极限不存在。
概念辨析：不要把"含参数、结果随参数分情况"误判为"极限不存在"
• 极限不存在：对同一个固定的 a，x→∞ 时函数不趋于任何确定值。
• 分情况：对不同的固定 a，结果不同；但每个 a 自己的极限都存在。
关键：题目说"设常数 a>0"，a 是固定常数、不是变量；对每个固定的 a，极限都存在，只是值取决于 a。
第二步：先化简 （黄金原则：先化简再动手——不要上来就洛必达/泰勒）
化简两板斧：
① 非零极限因子先算出来扔掉（如 1+cosx→2，直接提走）；
② 乘除因子优先等价无穷小替换。
【重点】等价无穷小替换 —— 只对乘除因子成立
常用等价无穷小（x→0）阶数
x ~ sinx ~ tanx ~ arcsinx ~ arctanx ~ ln(1+x) ~ ex−11 阶
ax−1 ~ x·lna；(1+x)α−1 ~ αx1 阶
1−cosx ~ (1/2)x22 阶
x−sinx ~ x3/6；arcsinx−x ~ x3/63 阶
tanx−x ~ x3/3；x−arctanx ~ x3/33 阶
x−ln(1+x) ~ (1/2)x22 阶
推广：x→a 时，若 □→1，则 ln□ ~ □−1（如 x→1 时 lnx ~ x−1）。
主项规则：替换要保留"第一个非零项（主项）"，0 不是主项
主项 = 泰勒展开里幂次最低、数值最大、起决定作用的那一项（x→0 时 x>x2>x3，幂次最低的非零项说了算）。
• 主项不抵消（两项主项不同、不等价）→ 能直接等价替换；
• 主项抵消（相减两项主项相同、等价）→ 不能直接换，要多展一阶。
经典的坑：∞−∞ 型主项抵消时，不能把非主项因子随手扔掉
本质：这里是加减项，不是乘除因子；只有乘除因子才能做等价无穷小替换——这个坑说白了就是"在加减项里错误地用了等价无穷小"。
情况能否去掉非主项因子（如 1−t）
乘除关系单独存在（如 A/[t2(1−t)] 单独出现）✓ 可以，1−t→1
加减关系（∞−∞ 型，主项抵消）✗ 不行，必须保留高阶项
反例：limt→0+ (et/t2 − 1/[t2(1−t)])。直接把 1/[t2(1−t)] 换成 1/t2 会错——主项 1/t2 抵消后，次项（高阶项）决定结果，必须多展一阶。
第三步：看式子类型，选工具
总纲：0/0、∞/∞ 是"母型"；其余未定式（0·∞、∞−∞、1∞、00、∞0）本质都是先化成 0/0 或 ∞/∞，再回第二步化简 / 上工具。
0/0 或 ∞/∞（母型，直接上工具）
• 有乘除因子 → 先等价无穷小（再回第二步化简）；
• 出现加减、高阶项消不掉 → 泰勒公式（首选，比洛必达稳）；
• 不好展开 → 洛必达（洛完仍 0/0 可再洛，但最多 2~3 次）；
（∞/∞ 型的快速判型：无穷大增长速度排序，见 ③.7）
泰勒公式工具（加减、高阶项消不掉时用它）
定理（皮亚诺余项）：f(x) = f(x₀) + f′(x₀)(x−x₀) + … + f(n)(x₀)/n!·(x−x₀)n + o((x−x₀)n)。
函数（x→0）展开
ex1 + x + x2/2! + x3/3! + … + xn/n! + o(xn)
sinxx − x3/3! + x5/5! − … + o(x2n)
cosx1 − x2/2! + x4/4! − … + o(x2n)
ln(1+x)x − x2/2 + x3/3 − … + o(xn)
(1+x)α1 + αx + α(α−1)/2!·x2 + … + o(xn)
嵌套展开（复合函数，合法标准做法）：先展内层 u=sinx 到够用的阶，再展外层 eu，代入合并、只保留到需要的阶。例：esinx 展到 x4，内层 sinx 展到 x3 就够（更高次代入后超过 x4）。
x→+∞ 时别硬套 x→0 的公式：如 arctanx 在 x→0 是 x−x3/3+…，x→+∞ 却是 π/2−1/x+1/(3x3)−…；核心是利用 arctanx + arctan(1/x) = π/2 倒推。
洛必达法则工具（不好展开时用）
4 个条件说明
① 0/0 或 ∞/∞类型要对
② 去心邻域可导x₀ 本身可不可导不管（极限只管邻域）
③ 分母导数 ≠ 0不能恒为 0（g′ 可以为 ∞）
④ lim f′/g′ 存在关键！A 为有限数或 ∞ 都成立，可推出 lim f/g = A
补充：洛完一次看 lim f′/g′ 的结果——① 有限数 → 直接得答案；② 是 ∞ 但 f′/g′ 不是未定式（如 f′ 非零、g′→0）→ 原极限就是 ∞，结束，不能再洛；③ f′/g′ 仍是 0/0 或 ∞/∞ 未定式 → 可继续对 f′/g′ 再洛（最多 2~3 次，避免死循环）。
数列不能直接用洛必达：n 只取正整数、离散，对 n 无法求导。正确做法（间接用）：① 把 n 换成连续变量 x，得 f(x)；② 对 limx→+∞ f(x) 用洛必达；③ 由海涅定理（归结原则）：函数极限存在（或为 ∞）⇒ 数列极限等于它。
例：求 limn→∞ ln n/n。令 f(x) = ln x/x：limx→∞ ln x/x = limx→∞ (1/x)/1 = 0，故数列极限 = 0。
其他五类 → 先化成 0/0 或 ∞/∞
• 0·∞：倒一个变 0/0 或 ∞/∞（把简单的那个放分母）；
• ∞−∞：选一种化成 0/0——
— 两项是分式（A/B − C/D）→ 通分；
— 含根号差（√−√ 或 √−x）→ 有理化（乘共轭因式）；
— x→∞ 含根号且次数高 → 提公因式 x；
— x→∞ 含 1/x → 倒代换 t=1/x。
例：limx→∞ [∛((x+a)(x+b)(x+c)) − x]：
① 提 x 出来：三次根号化成 x·[(1+u)1/3 − 1]；
② 等价无穷小：(1+u)α − 1 ~ αu，这里 α=1/3；
③ 乘积展开只取一次项：(1+at)(1+bt)(1+ct) = 1 + (a+b+c)t + o(t)，高次项 t→0 可忽略。
• 1∞：【专项】lim uv = elim v(u−1)，一步出结果（本质是 u→1 时 ln u ~ u−1 用了等价代换）；
• 00 / ∞0：幂指函数 uv 直接代是未定式，取对数化成 0·∞：
— 五步通用流程：
① 直接代是 00 / ∞0（未定式）；
② 令 y = uv，取对数 ln y = v·ln u；
③ 指数 v 被拉下来，变 0·∞ 型；
④ 倒代换 / 通分变 0/0 或 ∞/∞，洛必达；
⑤ 求出 lim ln y = A，则 lim y = eA。
— 关键：eu 处处连续，极限号可拿进函数：lim eg(x) = elim g(x)（前提 lim g(x) 存在）。
例：limx→0+ xx：
① ln y = x ln x；
② 0·∞ → lnx/(1/x)（∞/∞）；
③ 洛必达 = (1/x)/(−1/x2) = −x → 0；
④ 还原 lim y = e0 = 1。
B. 数列求极限 （n→∞）
拿到数列极限，先按四步决策树判类
① 能不能直接算？能 → 代入 / 公式直接出。
② 是 n 项和 / n 项积？
— 能提出 1/n、剩下 f(k/n) → 定积分定义；
— 提不出 1/n → 只能放缩 → 夹逼准则。
③ 是递推 xn+1=f(xn)？ → 单调有界定理（证有界 → 证单调 → 设极限解方程）。
④ 都不像？ → 化函数极限（海涅定理，间接洛必达 / 泰勒）/ Stolz 定理。
方法一　n 项和 / n 项积
判据：通项是 Σ 或 Π 形式，项数随 n 增长。
分支 A：能提出 1/n → 定积分定义
limn→∞ (1/n) · Σk=1n f(k/n) = ∫01 f(x) dx
本质：把 [0,1] 切成 n 等份
— 每份宽度 = 1/n
— 右端点 = k/n
— 矩形面积和 → 定积分
凑法一：标准型（直接提 1/n）
原式：Σk=1n 1/(n+k)
提出 1/n：(1/n)·Σk=1n 1/(1+k/n)
写成积分：∫01 1/(1+x) dx
结果：= ln2
凑法二：分母有小扰动（小项忽略）
原式：Σk=1n k/(n²+k)
忽略分母小扰动 k：≈ (1/n)·Σk=1n (k/n)
写成积分：∫01 x dx
结果：= 1/2
分支 B：提不出 1/n → 夹逼准则
把通项放缩成两头能算出相同极限的式子
— 一头放大
— 一头缩小
— 两头极限相等 → 夹逼出结果
n 项积
先取对数：把乘积化成和
再走分支 A 或 B
方法二　递推数列 xn+1 = f(xn)
判据：通项不是显式公式，而是由前一项递推给出。
大题写法（必须证明，否则扣分）
① 证有界
— x1 有界
— 假设 xn 有界 ⇒ xn+1=f(xn) 也有界
— 归纳成立
② 证单调
— 算 xn+1 − xn 的符号
— 或看 f 是否单调
③ 设极限解方程
— 设 limn→∞ xn = A
— 代入递推式：A = f(A)
— 解方程求根
选择填空（不用写证明，心算）
① 直接设 limn→∞ xn = A
② 代入 A = f(A)，解方程
③ 心算前 2–3 项，看单调方向
④ 选合理的根（排除矛盾根）
⑤（可选）快速验有界
例题：x1 = √2，xn+1 = √(2+xn)，求极限
第 1 步　设极限为 A
A = √(2+A)
第 2 步　两边平方解方程
A² = 2 + A
A² − A − 2 = 0
A = 2　或　A = −1
第 3 步　心算前几项，看方向
x1 ≈ 1.414
x2 ≈ 1.848
x3 ≈ 1.962
递增，向 2 靠拢
第 4 步　选根
选 A = 2
舍 A = −1（数列恒正）
依据　极限等式性质
若 f(x) = g(x)，且 lim f(x) = A、lim g(x) = B
则 A = B
→ 递推式可以两边同时取极限
方法三　不好分类（既不是 n 项和/积，也不是递推）
分支 A：化函数极限（间接用洛必达 / 泰勒）
核心：数列 n 是离散整数、不可导，不能直接对数列洛必达
海涅定理（归结原则）：
若 limx→+∞ f(x) = A　则　limn→∞ f(n) = A
三步做法：
① 把 n 换成连续变量 x
② 写成 limx→+∞ f(x)
③ 对 f(x) 用洛必达 / 泰勒（满足 0/0 或 ∞/∞）
④ 函数极限 = A ⇒ 数列极限也 = A
分支 B：Stolz 定理
适用 —0/0 或 ∞/∞ 型数列
相当于"数列版洛必达"
具体公式待后续补充

C. 抽象函数求极限 （无具体表达式，靠极限等式 / 导数信息 / 递推式推理）
解题总流程（两步）
① 读题：f(x) 给了什么条件？——极限等式 / 函数值导数值 / 待求参数 / 递推式
② 选方法：按下表对号入座，每个题型内部自带展开与计算细节
题型 1　已知一个极限等式 → 求另一个极限
特征：已知 lim [A(x)+B(x)f(x)]/C(x) = L，求 lim [D(x)+E(x)f(x)]/F(x)
方法一：拆分凑形法（优先，快）：在分子上加减同一项，把已知式拆成"已知函数部分 + 目标式部分"，移项直接算出目标极限。
方法二：泰勒对比系数法（通用，稳）：
1. 把已知函数按分母阶数泰勒展开；
2. 与已知极限式对比系数，反推出 f(x) 的渐近行为；
3. 代入目标式，约掉无穷小即得结果。
典型例题：已知 limx→0 [sin3x2 + x2f(x)]/x6 = 0，求 limx→0 [3+f(x)]/x4。
题型 2　已知 f(0), f′(0) → 求含 f(x) 的极限
特征：题目给出 f(0)=a、f′(0)=b，且 f 连续或可导。
方法一：导数定义法（一阶简单题）：凑出 [f(x)−f(0)]/x = f′(0)，直接代入即可。
方法二：泰勒展开法（高阶 / 复合题）：按目标式所需阶数展开：
f(x) = f(0) + f′(0)x + f″(0)/2·x2 + o(x2)
展开后代入极限式，消去非零常数项，保留目标阶数的系数。
典型例题：已知 f(0)=0, f′(0)=2，求 limx→0 f(x)/x。
题型 3　反求参数
特征：已知极限存在、或等于某定值，求 a, b 等参数。
方法：把含参数的式子泰勒展开到目标阶数——
• 若"极限存在" → 令所有低阶项系数 = 0；
• 若"极限 = 某定值" → 低阶项系数 = 0，目标阶系数 = 该定值。
逐项列方程，解出 a, b。
典型例题：求 a, b 使 limx→0 [∛(1−x6) − ax2 − b] = 0。
题型 4　递推数列求极限
特征：xn+1 = g(xn)，求 limn→∞ xn。
方法：设 limn→∞ xn = A，对递推式两边取极限：A = g(A)，解方程求根。
高频易错
• 大题：必须先证单调有界，再取极限，否则扣分。
• 选择填空：可直接设 A 解方程 + 心算选根，不用证明。
